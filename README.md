# Review and Verification

## Four-Dimension Review

Every workplace output should be checked across four dimensions:

| Dimension | Review |
|---|---|
| Accuracy | Factual and policy-related claims must be verified before use |
| Tone | Output should be professional, empathetic and action-oriented |
| Compliance | Compensation decisions and policy changes must remain under authorised human control |
| Context | Classification must be appropriate for an airline baggage-service environment |

---

# Hallucination Audit

| AI-Generated Claim | Evidence | Status | Action |
|---|---|---|---|
| Baggage classification: DELAYED | Based on sample complaint | Supported within example | Retained |
